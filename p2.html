What are we investigating?

The controller does not see the true plant output directly. It receives the sensor measurement, and a slow sensor takes time to follow changes in the true output. Increase the sensor time constant (τs) and observe how the measured signal lags behind the real system response.

The feedback error is calculated from the sensor measurement: e(t) = r(t) − ym(t), not from the true output y(t).

4. How the Simulation Works

The plant is modeled as a first-order system:

dy/dt = (K · u − y) / τ

The sensor is also modeled as a first-order system:

dym/dt = (y − ym) / τs

The PID controller uses the measured output to calculate the error:

e = r − ym    and    u = Kp·e + Ki·∫e dt + Kd·de/dt

This page uses the Euler numerical method. At each small time step, it estimates the change in the plant and sensor outputs, then advances the simulation.
