6. Understanding the Results

Amplitude Ratio: It describes how much the system reduces or changes the input signal amplitude.

Phase Lag: It represents the delay in phase between the input and output signals.

Dynamic Error: It is calculated as the difference between the amplitude ratio and one.

Cutoff Frequency: It is the frequency where the amplitude ratio becomes approximately 0.707.

The time constant affects the system response. A larger time constant generally means a slower response.
